# CS50 Tiny Search Engine (TSE) Crawler

## Usage

To build , run `make`, then run `make test`
If this is not your first time running it, run `make clean`, then `make`, then run `make test`

## Overview

 * `crawler.c` - file that does all the crawling of webpages
 * `Makefile` - complies all needed files and can run tests
 * `testing.sh` - testing script for error checking and sample tests
 * `testing.out` - output of testing.sh, mostly errors from errant commands
