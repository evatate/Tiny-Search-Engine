# CS50 Tiny Search Engine (TSE) Common

## Usage

To build , run `make`, then run `make all`
If this is not your first time running it, run `make clean`, then `make`, then run `make all`

## Overview

 * `pagedir.c` - has two main functions, create a directory for outputs, creates indivual output files for each url with a unique docID
 * `Makefile` - complies all needed files, mainly for pagedir
